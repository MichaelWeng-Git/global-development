# Global Development

A zoom-in field guide for my Humanity unit on global development — why are some countries rich and some poor?

The page zooms from the whole planet down to one room in one house:

**Earth → Asia → Philippines → Manila → Tondo → A house → Inside**

Each stop pairs quick facts and Gapminder data (income levels, life expectancy, literacy, poverty trends) with a short reflection. The three lessons I took away — money, people and knowledge as the things that keep a family in its layer of society — sit at the bottom of the zoom.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The page (loads the images next to it) |
| `index.standalone.html` | Single-file version with every image inlined — open it anywhere, offline |
| `*.png` | Illustrations for each zoom level |

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
